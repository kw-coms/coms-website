# 후속 작업 · 한눈에 보기 홈

기존 스크롤형 홈과 함께 주요 메뉴를 첫 화면에서 찾는 컴팩트한 홈을 제공한다. 게시물과 활동의 전문은 각 페이지에서 열고, 홈에서는 방문 목적에 맞는 경로를 빠르게 고를 수 있게 한다.

## 첫 화면 구성

- 공통 영역에는 COM’s 이름과 짧은 동아리 소개를 배치한다. 동아리 소개, 활동·스터디, 팀 프로젝트·작품, 해커톤·외부 일정, 모집·지원, 협업 문의를 같은 화면에서 찾아갈 수 있게 한다.
- 회원 홈은 최신 공지 한 건, 커뮤니티·자료실, 월별 일정·팀 프로젝트·활동 도구를 앞에 배치한다. 공지나 일정이 비어 있어도 해당 목록으로 이동하는 링크를 제공한다.
- 넓은 화면은 소개와 바로가기 그룹이 첫 화면에 읽히도록 구성한다. 모바일은 같은 우선순위로 쌓아 스크롤하며 읽고, 주요 버튼의 터치 영역을 충분히 확보한다.

## 사용자가 고르는 홈

- 기존 스크롤형 홈을 기본으로 두고 화면 설정에서 ‘스크롤형’과 ‘한눈에 보기’를 전환할 수 있게 한다. 이 브라우저에서 새로고침한 뒤에도 선택이 유지되도록 한다.
- 네 가지 화면 테마와 홈 구성을 독립적으로 고를 수 있게 한다. 컴팩트형은 작은 머리말과 메뉴 그룹이 중심인 별도 레이아웃으로 만든다.
- 기존 `/#about`, `/#activities`, `/#projects`, `/#recruit` 공유 링크의 이동을 보장한다. 회원 기능과 최신 공지는 기존 인증 및 권한을 따른다.

## 시작점과 확인 기준

- 홈과 권한별 콘텐츠는 [HomeView](../../../src/pages/home/HomeView.tsx), 기존 링크와 문구는 [homeContent](../../../src/data/homeContent.ts), 설정 메뉴는 [AppearanceControl](../../../src/components/AppearanceControl.tsx)에서 확인한다.
- Playwright에서 1280×720 데스크톱, 390px 모바일, 회원·비회원, 테마 변경, 새로고침 및 해시 링크를 확인한다. 첫 화면 캡처에는 공개 콘텐츠와 테스트 데이터만 넣는다.
