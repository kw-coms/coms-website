콘솔 프로그램 만들기

프로그래밍이 처음이어도 괜찮습니다. 이 페이지를 순서대로 따라 하면 변수 → 조건·반복 → 배열 → 메서드 → 클래스까지 배우고, 마지막에는 메뉴가 있는 성적 관리 프로그램을 직접 완성합니다. 모든 예제는 JDK 17 이상에서 컴파일하고 실행해서 출력 결과를 직접 확인한 코드입니다.

Java 17+ (JDK 21 이상의 LTS 권장)콘솔 프로그램객체지향 맛보기

0. 시작하기

자바가 무엇인지 알아보고, 개발 도구를 설치해서 첫 프로그램을 실행해 봅니다.

0-1자바는 어떤 언어일까?

자바(Java)는 안드로이드 앱, 은행·쇼핑몰 서버, 대기업 백엔드까지 폭넓게 쓰이는 언어입니다. 우리 동아리 웹사이트의 백엔드(서버)도 자바 기반의 Spring Boot로 만들어져 있어요. 자바의 가장 큰 특징은 "한 번 컴파일해서 어디서나 실행"입니다.

  • 컴파일(compile): 사람이 쓴 코드(.java)를 컴퓨터가 읽을 수 있는 중간 형태(.class, 바이트코드)로 번역하는 일. 이때 문법 오류도 걸러줍니다.
  • JVM (Java Virtual Machine): 바이트코드를 실제로 실행해 주는 "자바 전용 가상 컴퓨터". Windows, macOS, Linux마다 JVM이 따로 있어서 같은 .class 파일이 어디서나 돌아갑니다.
  • JDK (Java Development Kit): 개발에 필요한 도구 묶음. 컴파일러 javac, 실행기 java, JVM이 모두 들어 있습니다. 우리가 설치할 것이 바로 이것입니다.

2. 변수와 자료형

값을 저장해 두는 이름표(변수)와, 값의 종류(자료형)를 배웁니다.

2-1자료형 종류

자바는 변수를 만들 때 어떤 종류의 값을 담을지 먼저 정해야 합니다. 형식은 자료형 이름 = 값; 입니다.

자료형담는 값예

long아주 큰 정수. 숫자 끝에 Llong big = 3_000_000_000L;
double소수가 있는 실수double height = 175.5;
boolean참/거짓 (true, false)boolean ok = true;
char글자 한 개, 작은따옴표char grade = 'A';
String문자열(글자 여러 개), 큰따옴표. 대문자 S 주의!String name = "민수";
public class Variables {
    public static void main(String[] args) {
        int age = 20;                  // 정수
        long big = 3_000_000_000L;     // 아주 큰 정수 (끝에 L)

2-2계산과 형변환

가장 자주 틀리는 부분입니다. 정수끼리 나누면 결과도 정수라서 소수점이 사라져요. 하나를 double로 바꾸면(형변환, 캐스팅) 실수 나눗셈이 됩니다.

public class Casting {
    public static void main(String[] args) {
        int a = 7, b = 2;
        System.out.println(a / b);           // 정수 / 정수 = 정수
        System.out.println(a % b);           // 나머지
        System.out.println((double) a / b);  // 하나를 double로 바꾸면 실수 나눗셈
        System.out.println(a / 2.0);

        double avg1 = (90 + 85 + 100) / 3;    // 함정!
        double avg2 = (90 + 85 + 100) / 3.0;
        System.out.println(avg1 + " vs " + avg2);

        int cut = (int) 3.99;                 // 소수점 버림
        System.out.println(cut);

        char c = 'A';
        System.out.println(c + 1);            // int가 됨
        System.out.println((char) (c + 1));   // 다시 char로

        System.out.println("1" + 2);          // 문자열 이어붙이기
        int n = Integer.parseInt("42") + 1;   // 문자열 -> 정수
        System.out.println(n);

        final double PI = 3.14159;            // 상수: 바꿀 수 없음
        var radius = 5;                       // 타입 추론: int
        var message = "원 넓이";                // 타입 추론: String
        System.out.println(message + " = " + PI * radius * radius);
    }
}

  • 돌려줄 게 없으면 반환 타입을 void로 쓰고 return은 생략합니다.
  • 호출은 add(3, 4)처럼 이름과 재료를 넘기면 끝. 결과를 변수에 담거나 바로 출력에 쓸 수 있습니다.
public class Methods {
    static int add(int a, int b) {
        return a + b;

    static double add(double a, double b) {   // 오버로딩: 이름 같고 매개변수 다름

    }

6-2static이란?

static이 붙은 메서드는 객체를 만들지 않고도 바로 부를 수 있는 메서드입니다. 우리는 아직 객체를 배우지 않았으니, 지금은 "main에서 부르는 메서드에는 static을 붙인다"고 기억하세요. 7장에서 static이 없는 메서드(객체의 메서드)와 비교합니다. static을 빼고 main에서 부르면 non-static method ... cannot be referenced from a static context 에러가 납니다.

6-3오버로딩

예제에 add가 두 개 있습니다. 이름은 같고 매개변수의 종류나 개수가 다르면 같은 이름의 메서드를 여러 개 만들 수 있습니다(오버로딩). 호출할 때 넘긴 값에 맞는 것이 자동으로 선택됩니다. add(3, 4)는 int 버전, add(1.5, 2.5)는 double 버전이 실행돼서 결과가 7, 4.0으로 다르죠. println이 숫자든 문자열이든 다 출력할 수 있는 것도 오버로딩 덕분입니다.

메서드를 나누는 기준한 메서드는 한 가지 일만 하게 만드세요. "평균 구하기", "짝수인지 확인하기"처럼 이름만 봐도 하는 일이 보이면 좋은 메서드입니다. 같은 코드를 복사해서 붙이고 싶어질 때가 메서드로 묶을 타이밍입니다.

7. 클래스와 객체

관련된 데이터(필드)와 동작(메서드)을 한 덩어리로 묶는, 자바의 핵심 개념입니다.

7-1클래스 = 설계도, 객체 = 실제 물건

"학생"이라는 개념에는 이름, 점수 같은 데이터와 합격인지 확인하는 동작이 함께 있습니다. 이걸 묶은 설계도가 클래스, 설계도로 찍어낸 실제 학생 한 명 한 명이 객체(인스턴스)입니다. 붕어빵 틀이 클래스, 붕어빵이 객체예요.

  • 필드: 객체가 가진 데이터 (name, score)
  • 생성자: new로 객체를 만들 때 처음 실행되는 특별한 메서드. 이름이 클래스와 같고 반환 타입이 없습니다.
  • this: "이 객체 자신". 매개변수 이름이 필드와 같을 때 this.name = name;처럼 구분해 줍니다.
  • 메서드: 객체가 할 수 있는 동작. static이 없는 메서드는 객체.메서드()로 부릅니다.

7-2캡슐화: private + getter/setter

필드를 private으로 숨기고, 읽기·쓰기는 getter / setter 메서드로만 허용하는 것을 캡슐화라고 합니다. 이렇게 하면 잘못된 값이 들어오는 것을 막을 수 있습니다. 아래 setScore는 0~100이 아닌 점수를 거절합니다. 필드를 public으로 열어두면 누구나 score = 9999를 넣을 수 있어요.

toString()은 객체를 문자열로 바꿔주는 약속된 메서드입니다. 만들어 두면 System.out.println(a)처럼 객체를 바로 출력할 수 있어요. (안 만들면 Student@1b6d3586 같은 알 수 없는 글자가 나옵니다.) @Override는 "부모의 메서드를 내가 다시 정의한다"는 표시로, 8장에서 자세히 봅니다.

public class Main {
    public static void main(String[] args) {
        Student a = new Student("민수", 80);
        Student b = new Student("지영", 95);

        a.setScore(88);
        a.setScore(150);                 // 범위 밖: 무시됨
        System.out.println(a);
        System.out.println(b.getName() + "의 점수: " + b.getScore());
        System.out.println(a.isPass() + " " + b.isPass());
    }
}

class Student {
    private String name;    // private: 밖에서 직접 못 건드림
    private int score;

    Student(String name, int score) {   // 생성자: 이름이 클래스와 같고 반환 타입 없음
        this.name = name;               // this.name = 필드, name = 매개변수
        this.score = score;
    }

    String getName() {
        return name;
    }

    int getScore() {
        return score;
    }

    void setScore(int score) {
        if (score < 0 || score > 100) {
            System.out.println("점수는 0~100 사이여야 해요: " + score);
            return;
        }
        this.score = score;
    }

    boolean isPass() {
        return score >= 60;
    }

    @Override
    public String toString() {
        return "Student{name=" + name + ", score=" + score + "}";
    }
}

8. 상속과 인터페이스 맛보기

이미 만든 클래스를 물려받아 확장하고, "이런 일을 할 수 있어야 한다"는 약속을 정하는 방법입니다.

8-1extends와 super

동물은 모두 이름이 있고 소리를 냅니다. 이런 공통 부분을 Animal에 한 번만 쓰고, Dog와 Cat은 extends로 물려받아 다른 부분만 새로 씁니다.

  • super(name): 부모 클래스의 생성자를 호출합니다. 자식 생성자의 첫 줄에 써야 해요.
  • @Override: 부모의 메서드를 자식이 같은 이름으로 다시 정의(재정의)한다는 표시. 오타가 나면 컴파일러가 알려줘서 안전합니다.
  • protected: 자식 클래스에서는 접근할 수 있지만 외부에서는 못 쓰는 접근 수준.

8-2다형성

자식 객체는 부모 타입 변수에 담을 수 있습니다. 아래 Animal[] zoo에는 Dog, Cat, Animal이 섞여 있는데, a.introduce()를 똑같이 불러도 실제 객체가 무엇이냐에 따라 다르게 동작합니다. 이것이 다형성입니다. 새 동물을 추가해도 반복문을 고칠 필요가 없어요.

8-3interface

인터페이스는 "이런 메서드를 반드시 가져야 한다"는 약속(몸통 없는 메서드 목록)입니다. 클래스는 implements로 이 약속을 지키겠다고 선언하고 내용을 채웁니다. 클래스는 부모를 하나만 extends 할 수 있지만, 인터페이스는 여러 개를 implements 할 수 있습니다. 인터페이스의 메서드는 자동으로 public이라서, 구현하는 쪽도 public을 붙여야 합니다.

public class Main {
    public static void main(String[] args) {
        Animal[] zoo = { new Dog("바둑이"), new Cat("나비"), new Animal("누구게") };
        for (Animal a : zoo) {
            a.introduce();        // 같은 호출인데 객체마다 다르게 동작 = 다형성
        }

        Swimmable s = new Dog("해피");   // 인터페이스 타입으로도 받을 수 있다
        s.swim();
    }
}

interface Swimmable {
    void swim();                  // 몸통 없이 "할 수 있어야 하는 일"만 약속
}

class Animal {
    protected String name;

    Animal(String name) {
        this.name = name;
    }

    String sound() {
        return "...";
    }

    void introduce() {
        System.out.println(name + ": " + sound());
    }
}

class Dog extends Animal implements Swimmable {
    Dog(String name) {
        super(name);              // 부모 생성자 호출
    }

    @Override
    String sound() {
        return "멍멍!";
    }

    @Override
    public void swim() {
        System.out.println(name + "가 헤엄칩니다.");
    }
}

class Cat extends Animal {
    Cat(String name) {
        super(name);
    }

    @Override
    String sound() {
        return "야옹~";
    }
}

9. 예외 처리

프로그램이 실행 중에 만나는 문제(예외)를 미리 대비해서, 멈추지 않고 우아하게 처리하는 방법입니다.

9-1try / catch / finally

사용자가 숫자 칸에 "abc"를 쓰는 것처럼 코드 실수가 아니라 상황 때문에 생기는 문제를 예외라고 합니다. 예외가 날 수 있는 코드를 try에 넣고, 예외가 나면 catch가 대신 처리합니다. finally는 예외가 나든 안 나든 항상 마지막에 실행됩니다.

예외언제 생기나

public class Exceptions {
    static void checkAge(int age) {
        if (age < 0) {
            throw new IllegalArgumentException("나이는 음수일 수 없어요: " + age);
        }
        System.out.println("나이 OK: " + age);

    public static void main(String[] args) {
        try {
            int n = Integer.parseInt("abc");
            System.out.println("여기는 실행되지 않음 " + n);
        } catch (NumberFormatException e) {
            System.out.println("숫자가 아니에요: " + e.getMessage());
        } finally {
            System.out.println("finally는 무조건 실행");

            int zero = 0;

            System.out.println("0으로 나눌 수 없어요: " + e.getMessage());
        }

        try {
            checkAge(20);
            checkAge(-5);
        } catch (IllegalArgumentException e) {
            System.out.println("잡았다: " + e.getMessage());
        }
        System.out.println("프로그램은 계속 진행!");
    }
}

  • 예외가 나도 catch로 처리하면 프로그램은 계속 진행됩니다. 마지막 줄이 출력된 것을 확인하세요.

9-2입력 검증: 올바를 때까지 다시 묻기

3장에서 배운 "한 줄씩 읽고 변환"과 예외 처리를 합치면, 사용자가 이상한 값을 넣어도 죽지 않는 입력 코드를 만들 수 있습니다. 실습에서도 이 패턴을 씁니다.

import java.util.Scanner;

public class SafeInput {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int age = 0;
        while (true) {
            System.out.print("나이를 입력하세요: ");
            String line = sc.nextLine();
            try {
                age = Integer.parseInt(line.trim());
                if (age < 0) {
                    System.out.println("0 이상이어야 해요.");
                    continue;
                }
                break;                       // 올바른 입력: 반복 끝
            } catch (NumberFormatException e) {
                System.out.println("숫자만 입력해 주세요.");
            }
        }
        System.out.println("입력한 나이: " + age);
    }
}
나이를 입력하세요: abc
숫자만 입력해 주세요.
나이를 입력하세요: -3
0 이상이어야 해요.
나이를 입력하세요: 20
입력한 나이: 20

while (true) 무한 반복 안에서, 올바른 값이 들어왔을 때만 break로 빠져나옵니다. continue는 음수일 때 다음 차례로 넘어가 다시 묻게 합니다.

7장에서 배운 내용 그대로입니다. 필드는 private final로 만들어 한 번 정하면 못 바꾸게 했고(값을 바꾸는 기능이 필요 없으니까요), 합계와 평균을 계산하는 메서드를 넣었습니다. getTotal() / 3.0으로 나눠서 정수 나눗셈 함정을 피한 점을 확인하세요. String.format은 printf와 같은 서식인데 출력하지 않고 문자열로 돌려줍니다.

public class Student {
    private final String name;
    private final int korean;
    private final int english;
    private final int math;

    public Student(String name, int korean, int english, int math) {
        this.name = name;
        this.korean = korean;
        this.english = english;
        this.math = math;
    }

    public String getName() {
        return name;
    }

    public int getTotal() {
        return korean + english + math;
    }

    public double getAverage() {
        return getTotal() / 3.0;
    }

    @Override
    public String toString() {
        return String.format("%s: 국어 %d, 영어 %d, 수학 %d (합계 %d, 평균 %.1f)",
                name, korean, english, math, getTotal(), getAverage());
    }
}

2단계 코드에서 바뀌는 곳은 두 군데입니다. 먼저 main의 switch에 case 3 -> findStudent();, case 4 -> removeStudent();, case 5 -> showClassAverage();를 추가하고 printMenu에 메뉴 글자 3줄을 더합니다. 그다음 메서드 세 개 findStudent, removeStudent, showClassAverage를 클래스 맨 아래에 추가합니다. 코드에서 눈여겨볼 점은 이렇습니다. 문자열 비교에 ==가 아니라 equals를 쓴 점, 삭제할 때 사용자에게 보이는 번호(1부터)에서 1을 빼서 인덱스(0부터)로 바꾼 점(no - 1), 학생이 없을 때를 먼저 걸러내는 점(빈 리스트 방어)을 눈여겨보세요.

아래는 완성된 GradeApp.java 전체입니다. 2단계와 비교하며 위 내용을 찾아보세요. (Student.java는 1단계 그대로입니다.) 막혔다면 펼쳐서 내 코드와 비교해 보세요.

import java.util.ArrayList;
import java.util.Scanner;

public class GradeApp {
    private static final Scanner sc = new Scanner(System.in);
    private static final ArrayList<Student> students = new ArrayList<>();

    public static void main(String[] args) {
        while (true) {
            printMenu();
            int choice = readInt("선택: ");
            switch (choice) {
                case 1 -> addStudent();
                case 2 -> listStudents();
                case 3 -> findStudent();
                case 4 -> removeStudent();
                case 5 -> showClassAverage();
                case 0 -> {
                    System.out.println("종료합니다.");
                    return;
                }
                default -> System.out.println("없는 메뉴입니다.");
            }
        }
    }

    private static void printMenu() {
        System.out.println();
        System.out.println("===== 성적 관리 =====");
        System.out.println("1. 학생 추가");
        System.out.println("2. 전체 목록");
        System.out.println("3. 이름으로 찾기");
        System.out.println("4. 학생 삭제");
        System.out.println("5. 반 평균");
        System.out.println("0. 종료");
    }

    // 한 줄을 읽어 정수로 바꾼다. 잘못 입력하면 다시 묻는다.
    private static int readInt(String prompt) {
        while (true) {
            System.out.print(prompt);
            try {
                return Integer.parseInt(sc.nextLine().trim());
            } catch (NumberFormatException e) {
                System.out.println("숫자만 입력해 주세요.");
            }
        }
    }

    // 0~100 사이 점수만 받는다.
    private static int readScore(String prompt) {
        while (true) {
            int score = readInt(prompt);
            if (score >= 0 && score <= 100) {
                return score;
            }
            System.out.println("점수는 0~100 사이여야 해요.");
        }
    }

    private static void addStudent() {
        System.out.print("이름: ");
        String name = sc.nextLine().trim();
        int korean = readScore("국어: ");
        int english = readScore("영어: ");
        int math = readScore("수학: ");
        students.add(new Student(name, korean, english, math));
        System.out.println(name + " 학생을 추가했어요.");
    }

    private static void listStudents() {
        if (students.isEmpty()) {
            System.out.println("등록된 학생이 없어요.");
            return;
        }
        for (int i = 0; i < students.size(); i++) {
            System.out.println((i + 1) + ". " + students.get(i));
        }
    }

    private static void findStudent() {
        System.out.print("찾을 이름: ");
        String name = sc.nextLine().trim();
        for (Student s : students) {
            if (s.getName().equals(name)) {
                System.out.println(s);
                return;
            }
        }
        System.out.println(name + " 학생을 찾지 못했어요.");
    }

    private static void removeStudent() {
        listStudents();
        if (students.isEmpty()) {
            return;
        }
        int no = readInt("삭제할 번호: ");
        if (no < 1 || no > students.size()) {
            System.out.println("번호가 범위를 벗어났어요.");
            return;
        }
        Student removed = students.remove(no - 1);
        System.out.println(removed.getName() + " 학생을 삭제했어요.");
    }

    private static void showClassAverage() {
        if (students.isEmpty()) {
            System.out.println("등록된 학생이 없어요.");
            return;
        }
        double sum = 0;
        for (Student s : students) {
            sum += s.getAverage();
        }
        System.out.printf("반 평균: %.1f점 (%d명)%n", sum / students.size(), students.size());
    }
}

11-3NullPointerException

null은 "아무 객체도 가리키지 않는다"는 뜻입니다. 가리키는 게 없는데 메서드를 부르면 이 예외가 납니다. 초기화하지 않은 String 필드, 배열의 빈 칸(new String[2]의 값은 모두 null), 찾지 못해서 null을 돌려주는 메서드의 결과 등에서 자주 만납니다.

컴파일은 되지만 실행하면 에러가 나는 예제null인 문자열의 길이를 구하려고 합니다.
public class Npe {
    public static void main(String[] args) {
        String s = null;                 // 아무것도 가리키지 않음
        System.out.println(s.length());  // 없는 것에게 일을 시킴
    }
}
Exception in thread "main" java.lang.NullPointerException: Cannot invoke "String.length()" because "<local1>" is null
	at Npe.main(Npe.java:4)
  • 메시지의 Cannot invoke "String.length()" because "<local1>" is null은 "null인 변수에 length()를 부르려 했다"는 뜻입니다. 변수 이름이 <local1>으로 나오는 것은 컴파일할 때 이름 정보를 넣지 않아서이고, javac -g로 컴파일하거나 IDE에서 실행하면 실제 변수 이름(s)이 나옵니다.
  • at Npe.main(Npe.java:4) — 에러 난 파일과 줄 번호. 스택 트레이스는 항상 이 줄부터 읽습니다. 여러 줄이면 내가 쓴 파일 이름이 나오는 가장 위쪽 줄이 단서입니다.
  • 해결: 변수에 값이 들어가는지 확인하고, if (s != null)로 미리 검사하거나 처음부터 null이 되지 않게 설계합니다.

11-4막혔을 때 이렇게 해보세요

  1. 에러 메시지를 끝까지 읽기. 파일, 줄 번호, 원인이 다 적혀 있습니다.
  2. 영어 에러 메시지를 그대로 복사해서 검색. 거의 모든 에러는 누군가 이미 질문했습니다. (내 변수 이름은 빼고 검색)
  3. 의심 가는 곳에 System.out.println을 넣어서 변수 값이 내 생각과 같은지 확인. 가장 원시적이지만 가장 확실한 디버깅입니다. IntelliJ의 디버거(줄 옆을 클릭해 중단점 → Debug 실행)도 익혀 두면 좋아요.
  4. 코드를 작게 줄여서 문제가 되는 부분만 따로 실행해 보기.
  5. 그래도 안 되면 COM's 스터디방에 에러 메시지 전체와 코드를 올려 질문하기. 어디까지 해봤는지 함께 적으면 더 빨리 도움받을 수 있어요.
