처음 만드는 웹페이지
HTML · CSS · JavaScript

코딩을 처음 하는 사람도 이 페이지만 순서대로 따라오면 간단한 웹페이지를 직접 만들 수 있도록 구성했습니다. 모든 예제는 이 페이지 안에서 바로 고쳐보고 결과를 확인할 수 있어요.

HTMLCSSJavaScript

0. 시작하기

웹페이지가 무엇으로 이루어져 있는지, 그리고 무엇을 준비해야 하는지 알아봅니다.

웹페이지는 세 가지로 만들어진다

우리가 보는 모든 웹사이트는 결국 브라우저(크롬 등)가 텍스트 파일을 읽어서 화면에 그려준 결과입니다. 그 파일에 쓰는 언어가 세 가지예요. 집 짓기에 비유하면 이렇습니다.

HTML

뼈대·구조
여기에 제목, 여기에 사진, 여기에 버튼. "무엇이 있는지"를 정합니다.

CSS

인테리어·디자인
제목은 빨간색, 버튼은 둥글게. "어떻게 보이는지"를 정합니다.

JavaScript

전기·움직임
버튼을 누르면 메뉴가 열린다. "어떻게 동작하는지"를 정합니다.

순서도 이대로 배우는 게 좋습니다. HTML 없이 꾸밀 수 없고, 꾸밀 대상이 있어야 움직일 수 있으니까요.

준비물 (무료)

준비물용도
Chrome 브라우저만든 페이지를 열어보고, F12로 개발자 도구를 써서 오류를 확인합니다.
VS Code코드를 쓰는 편집기. code.visualstudio.com 에서 설치.
Live Server (VS Code 확장)저장할 때마다 브라우저가 자동으로 새로고침됩니다. VS Code 왼쪽 확장(Extensions) 탭에서 검색해 설치.

내 컴퓨터에서 첫 파일 만들기

  1. 바탕화면에 my-web 폴더를 만들고, VS Code에서 파일 → 폴더 열기로 엽니다.
  2. 새 파일을 만들고 이름을 index.html로 저장합니다. (확장자 .html이 중요!)
  3. 빈 파일에 ! 한 글자를 치고 Tab 키를 누르면 기본 뼈대가 자동으로 채워집니다.
  4. <body>와 </body> 사이에 안녕하세요!라고 쓰고 저장(Ctrl+S).
  5. 파일에서 우클릭 → Open with Live Server. 브라우저에 글자가 보이면 성공입니다.
이 페이지의 예제 사용법아래처럼 생긴 상자가 나오면, 위쪽 코드를 직접 고쳐보세요. 고치는 즉시 아래 결과가 바뀝니다. 탭(HTML/CSS/JS)을 눌러 파일을 바꿔 볼 수 있고, 망가뜨려도 되돌리기를 누르면 원래대로 돌아옵니다.

HTML1. HTML — 뼈대 만들기

HTML(HyperText Markup Language)은 "이건 제목, 이건 문단"처럼 내용에 이름표를 붙이는 언어입니다.

1-1태그란?

HTML은 태그로 내용을 감싸서 의미를 붙입니다. 태그는 꺾쇠 < >로 씁니다.

<p>안녕하세요</p>
↑ 여는 태그   ↑ 내용   ↑ 닫는 태그 (앞에 / 가 붙음)

태그에는 추가 정보인 속성을 붙일 수 있습니다. 이름="값" 형태로 여는 태그 안에 씁니다.

<a href="https://coms.kw.ac.kr">COM's 홈페이지</a>
   ↑ 속성 이름   ↑ 속성 값 (따옴표로 감쌈)

몇몇 태그는 감쌀 내용이 없어서 닫는 태그가 없습니다. 예: <img>(이미지), <br>(줄바꿈), <input>(입력칸).

태그 안에 태그를 넣을 수도 있습니다(중첩). 이때는 나중에 연 것을 먼저 닫아야 합니다.

<!-- 올바름 -->
<p>이건 <strong>중요</strong>해요</p>

<!-- 틀림: 순서가 엇갈림 -->
<p>이건 <strong>중요</p>해요</strong>
주석<!-- 이렇게 쓰면 --> 화면에 안 보이는 메모가 됩니다. 코드 설명을 남길 때 씁니다.

1-2모든 HTML 파일의 기본 뼈대

VS Code에서 ! + Tab으로 만든 뼈대가 바로 이것입니다. 외울 필요는 없고, 각 줄이 무슨 역할인지만 알면 됩니다.

<!DOCTYPE html>                 ← "이 파일은 HTML입니다" 선언
<html lang="ko">               ← 문서 전체. lang="ko"는 한국어 문서라는 뜻
<head>                          ← 화면에 안 보이는 설정 정보
  <meta charset="UTF-8">       ← 한글이 깨지지 않게 하는 설정
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
                                  ← 휴대폰에서도 알맞은 크기로 보이게
  <title>내 페이지</title>       ← 브라우저 탭에 뜨는 제목
</head>
<body>                          ← 실제로 화면에 보이는 내용은 전부 여기에!

</body>
</html>
이 페이지의 예제에서는매번 뼈대를 쓰면 길어지니까, 예제 상자에는 <body> 안에 들어갈 내용만 씁니다. 내 컴퓨터에서 연습할 때는 꼭 위 뼈대 안의 <body>에 넣으세요.

1-3글자를 표현하는 태그

태그뜻설명
<h1> ~ <h6>제목(heading)숫자가 작을수록 큰 제목. h1은 페이지에 보통 하나만.
<p>문단(paragraph)일반 글. 문단끼리는 자동으로 간격이 생김.
<br>줄바꿈HTML은 코드에서 엔터를 쳐도 줄이 안 바뀝니다. 바꾸려면 이걸 씀.
<strong>강조(굵게)중요한 내용.
<em>강조(기울임)말할 때 힘을 주는 부분.

1-4링크와 이미지

<a href="이동할 주소">클릭할 글자</a>
<img src="이미지 주소" alt="이미지 설명">
  • href: 이동할 주소. target="_blank"를 붙이면 새 탭에서 열립니다.
  • src: 이미지 파일 위치. 인터넷 주소도 되고, 내 폴더에 있는 cat.jpg 같은 파일 이름도 됩니다.
  • alt: 이미지가 안 뜰 때 나오는 글, 시각장애인용 화면 읽기 프로그램이 읽어주는 글. 꼭 쓰는 습관을 들이세요.
  • width: 이미지 너비(픽셀).
내 컴퓨터의 이미지 쓰기index.html과 같은 폴더에 photo.jpg를 넣었다면 src="photo.jpg", images 폴더 안에 넣었다면 src="images/photo.jpg"라고 씁니다. 이걸 상대 경로라고 해요.

1-5목록과 표

<ul>은 점 목록(unordered list), <ol>은 번호 목록(ordered list)이고, 각 항목은 <li>(list item)로 씁니다.

표는 <table> 안에 줄(<tr>)을 만들고, 줄 안에 칸을 넣습니다. 제목 칸은 <th>, 일반 칸은 <td>입니다.

1-6구역 나누기: div와 시맨틱 태그

지금까지는 글자를 다뤘다면, 이제 페이지를 구역(상자)으로 나눕니다. 나중에 CSS로 배치할 때 이 상자 단위로 움직이게 돼요.

  • <div>: 아무 의미 없는 상자. 묶어야 할 때 가장 많이 씁니다. 한 줄을 통째로 차지합니다.
  • <span>: 글자 일부만 감싸는 작은 상자. 줄을 바꾸지 않습니다.

div만 써도 되지만, 구역의 의미가 드러나는 시맨틱(semantic, 의미 있는) 태그를 쓰면 코드를 읽기 쉽고 검색엔진도 내용을 잘 이해합니다.

태그용도
<header>페이지 맨 위 (로고, 사이트 이름)
<nav>메뉴 (다른 페이지로 가는 링크 모음)
<main>페이지의 핵심 내용
<section>내용 안의 한 단락/주제
<footer>페이지 맨 아래 (연락처, 저작권)

1-7입력 받기: input, button

사용자에게서 무언가를 입력받을 때 씁니다. 지금은 모양만 만들고, 실제로 입력한 값을 쓰는 건 3장 JavaScript에서 합니다.

  • <input type="text">: 한 줄 입력칸. type을 password, email, number, checkbox, date 등으로 바꾸면 모양과 기능이 달라집니다.
  • placeholder: 입력칸에 흐리게 보이는 안내 문구.
  • <label>: 입력칸의 이름표. for 값과 input의 id를 같게 하면, 글자를 눌러도 입력칸이 선택됩니다.
  • <button>: 버튼.

CSS2. CSS — 꾸미기

CSS(Cascading Style Sheets)는 HTML 요소의 색, 크기, 위치를 정하는 언어입니다.

2-1CSS 문법과 HTML에 연결하는 방법

CSS는 "누구를" + "어떻게" 꾸밀지 쓰는 규칙의 모음입니다.

h1 {                ← 선택자: 누구를? (모든 h1을)
  color: red;        ← 속성: 값;  (글자색을 빨강으로)
  font-size: 40px;   ← 세미콜론(;)으로 하나씩 끝냄
}                   ← 중괄호로 묶음

HTML에 CSS를 적용하는 방법은 세 가지인데, 3번(별도 파일)을 쓰는 게 정석입니다.

<!-- 1. 태그에 직접 (inline) : 간단하지만 관리가 어려움 -->
<h1 style="color: red;">제목</h1>

<!-- 2. head 안에 style 태그 -->
<style>
  h1 { color: red; }
</style>

<!-- 3. 별도 파일 style.css를 만들고 head 안에서 연결 (권장) -->
<link rel="stylesheet" href="style.css">
이 페이지의 예제에서는CSS 탭에 쓴 내용이 3번처럼 자동으로 연결됩니다.

2-2선택자: 누구를 꾸밀지 고르기

선택자CSS에서HTML에서뜻
태그p { }<p>모든 p 태그
클래스.card { }<div class="card">class가 card인 것 전부 (점 . 으로 시작)
아이디#logo { }<div id="logo">id가 logo인 딱 하나 (샵 # 으로 시작)
자손nav a { }nav 안에 있는 a만
여러 개h1, h2 { }h1과 h2 둘 다
class vs idclass는 여러 요소에 같은 이름을 붙일 수 있고, 한 요소에 여러 개(class="card big")도 붙일 수 있습니다. id는 페이지에서 딱 하나만 존재해야 합니다. 꾸밀 때는 주로 class를 쓰세요.
규칙이 겹치면?위 예제에서 "하이라이트 문단"은 p(회색)와 .highlight(빨강) 규칙을 둘 다 받는데 빨강이 됩니다. 대략 id > class > 태그 순으로 더 구체적인 선택자가 이기고, 같은 수준이면 나중에 쓴 것이 이깁니다.

2-3색 · 글자 · 단위

속성예시설명
colorcolor: tomato;글자색
background-colorbackground-color: #f0f0f0;배경색
font-sizefont-size: 20px;글자 크기
font-weightfont-weight: bold;굵기 (normal, bold, 100~900)
text-aligntext-align: center;정렬 (left, center, right)
line-heightline-height: 1.6;줄 간격 (글자 크기의 1.6배)
width / heightwidth: 50%;너비 / 높이

색을 쓰는 방법: 이름(red), 16진수 코드(#ff0000), RGB(rgb(255, 0, 0)) 모두 같은 빨강입니다. VS Code에서 색 코드 옆 작은 네모를 누르면 색을 고를 수 있어요.

단위: px는 고정 크기, %는 부모 상자 대비 비율, rem은 기본 글자 크기(보통 16px)의 배수입니다. 처음엔 px와 %만 알아도 충분합니다.

2-4박스 모델: 모든 요소는 상자다

CSS에서 가장 중요한 개념입니다. 화면의 모든 요소는 아래처럼 네 겹의 상자로 이루어져 있습니다.

margin (바깥 여백: 다른 상자와의 거리)
border (테두리)
padding (안쪽 여백: 테두리와 내용 사이)
content (내용)
.card {
  padding: 20px;              ← 네 방향 모두 20px
  padding: 10px 20px;         ← 위아래 10px, 좌우 20px
  margin-top: 30px;           ← 한 방향만 (top, right, bottom, left)
  border: 2px solid black;   ← 두께 · 모양(solid 실선, dashed 점선) · 색
  border-radius: 12px;        ← 모서리를 둥글게
}
width가 생각보다 커지는 이유기본 설정에서는 width: 200px가 내용만의 너비라서, padding과 border가 더해져 실제로는 더 넓어집니다. CSS 파일 맨 위에 아래 코드를 넣어두면 width가 테두리까지 포함한 크기가 되어 계산이 쉬워집니다. 거의 모든 사이트가 이렇게 씁니다. 
* { box-sizing: border-box; }   ← * 는 "모든 요소"

2-5Flexbox: 상자를 가로로 나란히 배치하기

div는 기본적으로 한 줄씩 세로로 쌓입니다. 메뉴나 카드처럼 가로로 나란히 놓고 싶을 때 Flexbox를 씁니다. 핵심은 부모 상자에 display: flex를 주는 것입니다.

속성 (부모에 씀)뜻자주 쓰는 값
display: flex자식들을 가로로 나열
justify-content가로 방향 정렬flex-start, center, space-between, space-around
align-items세로 방향 정렬stretch, center, flex-start
gap자식 사이 간격10px
flex-direction나열 방향row(가로), column(세로)
flex-wrap넘치면 줄바꿈wrap

실제 사이트의 상단 메뉴는 대부분 이렇게 만듭니다.

2-6마우스 반응(hover)과 반응형

선택자 뒤에 :hover를 붙이면 마우스를 올렸을 때만 적용되는 스타일이 됩니다. transition을 주면 변화가 부드럽게 일어납니다.

반응형은 화면 크기에 따라 디자인을 바꾸는 것입니다. @media (max-width: 600px) { } 안에 쓴 규칙은 화면 너비가 600px 이하일 때만 적용됩니다.

✅ 확인 문제

Q1. <div class="menu">를 꾸미려면 CSS 선택자를 어떻게 써야 할까요?.menu — 클래스는 점(.)으로 시작합니다. id였다면 #menu.
Q2. 테두리와 내용 사이의 안쪽 여백은 margin과 padding 중 무엇일까요?padding — margin은 테두리 바깥, 다른 요소와의 거리입니다.
Q3. 세 개의 div를 가로로 나란히 놓으려면 어디에 무엇을 써야 할까요?세 div를 감싸는 부모에 display: flex; — 자식이 아니라 부모에 씁니다.
Q4. 다음 CSS가 동작하지 않는 이유는? .title { color: red } .title { font-size 20px; }font-size 뒤에 콜론(:)이 빠졌습니다. font-size: 20px; (참고로 마지막 속성의 세미콜론은 생략해도 동작하지만, 항상 쓰는 습관이 좋습니다.)
🧩 2장 미니 과제1장에서 만든 자기소개 페이지에 style.css를 연결해서 꾸며보세요. 조건: 상단에 Flexbox 메뉴, 내용은 카드 모양(padding + border-radius), 버튼 또는 링크에 hover 효과.

JS3. JavaScript — 움직이게 하기

JavaScript는 브라우저가 실행하는 프로그래밍 언어입니다. 버튼을 눌렀을 때 무언가 바뀌는 모든 기능이 JS로 만들어집니다.

3-1연결 방법과 콘솔

JS 파일 script.js를 만들고, HTML의 </body> 바로 위에서 연결합니다.

<body>
  <h1>내 페이지</h1>
  ... 내용 ...

  <script src="script.js"></script>   ← body가 끝나기 직전에!
</body>
왜 맨 아래에?브라우저는 HTML을 위에서부터 읽습니다. JS가 위에 있으면, 아직 만들어지지 않은 버튼을 찾으려다 오류가 납니다. (head에 두고 싶다면 <script src="script.js" defer></script>처럼 defer를 붙이면 됩니다.)

console.log(값)은 값을 콘솔에 출력합니다. 화면에는 안 보이고, 브라우저에서 F12 → Console 탭에서 볼 수 있어요. 코드가 제대로 도는지 확인할 때 가장 많이 씁니다. 이 페이지 예제에서는 결과 아래 콘솔 칸에 출력됩니다.

3-2변수와 자료형

변수는 값에 이름을 붙여 저장해두는 상자입니다.

const school = "광운대";   ← const: 한 번 넣으면 바꿀 수 없음 (기본으로 이걸 쓰기)
let score = 80;           ← let: 나중에 값을 바꿀 수 있음
score = 95;               ← let이라 가능. const였다면 오류
var는?옛날 방식이라 예상치 못한 문제를 일으킬 수 있습니다. 기본은 const, 바뀌어야 하는 값만 let으로 쓰세요.
자료형예시설명
숫자 (number)42, 3.14사칙연산 + - * /, 나머지 %
문자열 (string)"안녕", 'hi'따옴표로 감싼 글자
불리언 (boolean)true, false참/거짓. 조건문에서 사용
배열 (array)["사과", "배"]여러 값을 순서대로. 0번부터 셈
객체 (object){ name: "민수", age: 20 }이름(key)과 값(value)의 묶음

3-3조건문과 반복문

조건문: "만약 ~라면 이걸 하고, 아니면 저걸 해라."

if (조건) {
  // 조건이 true일 때 실행
} else if (다른 조건) {
  // 첫 조건은 false, 이 조건은 true일 때
} else {
  // 모두 false일 때
}

비교 연산자: ===(같다), !==(다르다), >, <, >=, <=. 조건 여러 개를 묶을 땐 &&(그리고), ||(또는).

= 와 === 는 다릅니다=는 값을 넣는 것(대입), ===는 같은지 비교하는 것입니다. ==(등호 두 개)도 있지만 "5" == 5가 true가 되는 등 헷갈리므로 항상 ===를 쓰세요.

반복문: 같은 일을 여러 번 할 때 씁니다.

for (let i = 0; i < 5; i++) {   ← i를 0부터 시작, 5보다 작은 동안, 1씩 증가
  console.log(i);                 ← 0, 1, 2, 3, 4 출력
}

for (const fruit of fruits) {     ← 배열의 값을 하나씩 꺼냄
  console.log(fruit);
}

3-4함수: 코드에 이름 붙이기

함수는 여러 줄의 코드를 묶어 이름을 붙인 것입니다. 한 번 만들어두면 이름만 불러서 몇 번이고 다시 쓸 수 있어요. 수학의 f(x)처럼 값을 받아서(매개변수) 결과를 돌려줄(return) 수 있습니다.

function 함수이름(매개변수) {   ← 만들기 (정의)
  // 할 일
  return 결과;               ← 결과를 돌려줌 (없어도 됨)
}

함수이름(값);                   ← 부르기 (호출): 이때 실제로 실행됨

3-5DOM 조작: JS로 HTML 바꾸기

여기서부터가 웹 JS의 진짜 핵심입니다. 브라우저는 HTML을 읽어서 DOM(Document Object Model)이라는 나무 구조로 만들어둡니다. JS는 document를 통해 이 나무에서 요소를 찾고, 바꿀 수 있습니다.

코드뜻
document.querySelector("선택자")CSS 선택자와 똑같은 방식으로 요소를 하나 찾음 ("#id", ".class", "p")
document.querySelectorAll("선택자")해당하는 요소를 전부 찾음
요소.textContent = "글자"안의 글자를 바꿈
요소.style.color = "red"스타일을 직접 바꿈 (background-color → backgroundColor처럼 하이픈 대신 대문자)
요소.classList.add("이름")class 추가 (remove 제거, toggle 있으면 빼고 없으면 넣기)
document.createElement("li")새 요소 만들기
부모.appendChild(자식)요소를 부모 안 맨 끝에 붙이기
요소.remove()요소 삭제
스타일은 class로 바꾸는 게 좋아요style.color로 하나하나 바꾸는 것보다, CSS에 미리 class를 만들어두고 JS에서는 classList로 붙였다 뗐다 하는 쪽이 관리하기 쉽습니다. 디자인은 CSS, 동작은 JS로 역할을 나누는 거예요.

3-6이벤트: 클릭하면 반응하게 만들기

지금까지의 JS는 페이지가 열리자마자 한 번 실행되고 끝났습니다. 이벤트를 쓰면 "사용자가 ~하면 이 함수를 실행해라"라고 예약할 수 있습니다.

요소.addEventListener("click", function () {
  // 요소를 클릭할 때마다 여기가 실행됨
});

자주 쓰는 이벤트: "click"(클릭), "input"(입력칸 내용이 바뀔 때), "keydown"(키보드 누를 때), "submit"(폼 제출), "mouseenter"(마우스 올릴 때).

입력칸에 적은 값은 입력칸.value로 꺼냅니다.

✅ 확인 문제

Q1. 나중에 값을 바꿀 변수는 const와 let 중 무엇으로 만들어야 할까요?let — const로 만든 변수에 다시 값을 넣으면 오류가 납니다.
Q2. const arr = ["a", "b", "c"];에서 "b"를 꺼내는 코드는?arr[1] — 배열은 0번부터 셉니다.
Q3. id가 submit인 버튼을 JS에서 찾는 코드는?document.querySelector("#submit") — CSS 선택자처럼 #을 붙입니다.
Q4. 버튼을 눌러도 아무 반응이 없고, 콘솔에 Cannot read properties of null이라는 오류가 뜹니다. 가장 흔한 원인 두 가지는?① querySelector의 선택자가 틀려서 요소를 못 찾음 (# 이나 . 빠뜨림, 오타) ② script 태그가 HTML 요소보다 위에 있어서 요소가 만들어지기 전에 실행됨. null은 "찾은 게 없다"는 뜻입니다.

4. 종합 실습: 할 일 목록 만들기

지금까지 배운 HTML · CSS · JS를 모두 써서 실제로 동작하는 작은 앱을 만듭니다.

만들 것

  • 입력칸에 할 일을 쓰고 추가를 누르면 목록에 생긴다.
  • 할 일 글자를 클릭하면 완료 표시(취소선)가 됐다 풀렸다 한다.
  • 삭제 버튼을 누르면 사라진다.

단계별 생각하기

  1. HTML: 제목, 입력칸, 추가 버튼, 그리고 할 일이 들어갈 빈 목록 <ul>을 만든다. 목록 항목은 JS가 만들 거라 비워둔다.
  2. CSS: 가운데 카드 모양으로, 입력칸과 버튼은 Flexbox로 나란히. 완료된 항목에 붙일 .done 클래스(취소선)를 미리 만들어둔다.
  3. JS: 추가 버튼에 click 이벤트 → 입력값을 꺼내서 → li를 만들고 → 목록에 붙인다. 만들 때 글자 클릭(완료)과 삭제 버튼 이벤트도 같이 달아준다.

코드에서 짚고 넘어갈 점

  • addBtn.addEventListener("click", addTodo)에서 addTodo 뒤에 괄호 ()가 없습니다. 괄호를 붙이면 "지금 바로 실행"이 되어버리고, 빼면 "클릭할 때 실행할 함수는 이거야"라고 넘겨주는 것이 됩니다.
  • return;은 함수를 그 자리에서 끝냅니다. 빈 칸일 때 아래 코드가 실행되지 않게 막는 역할이에요.
  • 완료 표시는 JS가 직접 취소선을 그리지 않고, done 클래스만 붙였다 뗍니다. 모양은 CSS가 담당합니다.

🚀 도전 과제

위 예제 상자에서 직접 코드를 고쳐서 기능을 추가해보세요. 막히면 힌트를 열어보세요.

도전 1. Enter 키를 눌러도 추가되게 하기입력칸에 keydown 이벤트를 달고, 눌린 키가 Enter인지 확인합니다. 
input.addEventListener("keydown", function (event) {
  if (event.key === "Enter") {
    addTodo();
  }
});
도전 2. "남은 할 일: N개" 표시하기HTML에 <p id="remain"></p>를 추가하고, 개수를 세서 표시하는 함수를 만든 뒤 추가·삭제·완료할 때마다 부릅니다. 
function updateRemain() {
  const all = document.querySelectorAll("#todo-list li").length;
  const done = document.querySelectorAll("#todo-list li.done").length;
  document.querySelector("#remain").textContent = `남은 할 일: ${all - done}개`;
}
도전 3. 새로고침해도 목록이 남아있게 하기 (어려움)브라우저의 localStorage에 저장합니다. 할 일 목록을 배열로 관리하고, 바뀔 때마다 localStorage.setItem("todos", JSON.stringify(배열))로 저장, 페이지가 열릴 때 JSON.parse(localStorage.getItem("todos"))로 불러와서 다시 그립니다. "localStorage 사용법"으로 검색해보세요. (이 페이지의 예제 상자 안에서는 보안상 동작하지 않으니 내 컴퓨터에서 해보세요.)
