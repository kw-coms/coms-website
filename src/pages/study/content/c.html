0. 시작하기

C가 어떤 언어인지, 코드를 실행하려면 무엇이 필요한지 알아봅니다.

C는 "컴파일해서 쓰는" 언어다

C는 1970년대에 만들어졌지만 지금도 운영체제, 임베디드 기기, 게임 엔진 등 빠르고 컴퓨터와 가까운 곳에서 널리 쓰입니다. 그리고 메모리가 어떻게 움직이는지 직접 보여주기 때문에, 한 번 배워두면 다른 언어를 이해하는 눈도 달라져요.

JavaScript처럼 파일을 바로 실행하는 언어와 달리, C는 컴파일러라는 번역기가 한 번 거쳐야 합니다.

소스 코드컴파일러실행 파일

기계어로 번역		→hello (윈도우는 hello.exe)

그래서 C는 "코드 수정 → 컴파일 → 실행"을 반복합니다. 코드를 고쳤는데 결과가 그대로라면 다시 컴파일했는지 먼저 확인하세요. 초보자가 제일 많이 하는 실수입니다.

1-3컴파일 에러 읽는 법

에러는 실패가 아니라 컴파일러가 보내주는 힌트입니다. 일부러 틀린 코드로 연습해 봅시다. 아래 두 코드는 일부러 틀린 예이며 컴파일되지 않습니다.

틀린 예 1 — printf 뒤에 세미콜론이 없습니다.

#include <stdio.h>

int main(void) {
    printf("Hello")
    return 0;
}
err1.c:4:20: error: expected ';' after expression
    4 |     printf("Hello")
      |                    ^
      |                    ;
1 error generated.

읽는 순서는 이렇습니다.

  1. err1.c:4:20 — 파일:줄:칸. 4번째 줄, 20번째 글자 근처입니다.
  2. error — 에러(실행 파일이 안 만들어짐). warning이면 경고라서 만들어지긴 하지만 고치는 게 좋습니다.
  3. expected ';' after expression — "세미콜론이 있어야 해요". 그 아래에 ;를 어디에 넣을지 화살표까지 알려줍니다.

틀린 예 2 — 선언하지 않은 변수를 썼습니다.

#include <stdio.h>

int main(void) {
    x = 5;
    printf("%d\n", x);
    return 0;
}
err2.c:4:5: error: use of undeclared identifier 'x'
    4 |     x = 5;
      |     ^
err2.c:5:20: error: use of undeclared identifier 'x'
    5 |     printf("%d\n", x);
      |                    ^
2 errors generated.
에러를 만났을 때① 맨 위 에러부터 고치세요. 하나가 다음 에러를 연쇄적으로 만들기도 합니다. ② 에러가 가리키는 줄이 그 앞줄의 문제일 수 있어요(세미콜론이 대표적). ③ 컴파일러마다 문구는 다릅니다. 위 출력은 macOS의 clang 기준이고, gcc는 표현이 조금 달라도 줄 번호와 의미는 비슷합니다.

2. 변수와 자료형

값을 저장하는 상자(변수)와, 상자의 종류(자료형), 값을 출력하고 입력받는 방법을 배웁니다.

2-1변수와 자료형

변수는 값을 담는 이름 붙은 상자입니다. C에서는 상자를 만들 때 어떤 종류의 값을 담을지(자료형)를 반드시 먼저 정해야 합니다.

자료형담는 값예
int정수int age = 20;
double실수(소수)double height = 175.5;
char글자 한 개 (작은따옴표)char grade = 'A';

=는 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣어라"(대입)입니다. 변수 이름은 영문자·숫자·밑줄(_)만 쓰고, 숫자로 시작할 수 없으며, 의미가 드러나게 짓는 게 좋습니다.

자료형마다 상자의 크기가 다릅니다. sizeof로 바이트 수를 확인할 수 있어요.

#include <stdio.h>

int main(void) {
    printf("char      : %zu바이트\n", sizeof(char));
    printf("int       : %zu바이트\n", sizeof(int));
    printf("long long : %zu바이트\n", sizeof(long long));
    printf("double    : %zu바이트\n", sizeof(double));
    return 0;
}
char      : 1바이트
int       : 4바이트
long long : 8바이트
double    : 8바이트
컴퓨터마다 다를 수 있어요위 출력은 일반적인 64비트 PC/Mac 기준입니다. int가 보통 4바이트(약 ±21억까지)라서, 그보다 큰 수를 넣으면 값이 이상해지는 오버플로가 일어납니다. 아주 큰 정수는 long long을 쓰세요.
초기화하세요int x;처럼 값을 주지 않고 만든 변수에는 쓰레기 값이 들어 있습니다. 변수를 만들 때 int x = 0;처럼 처음 값을 넣는 습관을 들이세요.

2-2printf 서식

printf의 큰따옴표 안에 %로 시작하는 서식 지정자를 쓰면, 뒤에 나열한 값이 순서대로 그 자리에 들어갑니다.

서식출력할 것
%dint (정수)
%fdouble (실수, 기본 소수점 6자리)
%.2f실수를 소수점 아래 2자리까지 반올림
%cchar (글자 한 개)
%s문자열
%%퍼센트 기호 자체
#include <stdio.h>

int main(void) {
    int age = 20;
    double height = 175.5;
    char grade = 'A';

    printf("나이: %d\n", age);
    printf("키: %f\n", height);
    printf("키(소수 1자리): %.1f\n", height);
    printf("학점: %c\n", grade);
    printf("이름: %s\n", "홍길동");
    printf("%d + %d = %d\n", 3, 4, 3 + 4);
    return 0;
}
나이: 20
키: 175.500000
키(소수 1자리): 175.5
학점: A
이름: 홍길동
3 + 4 = 7

175.5가 175.500000으로 나온 것처럼, %f는 항상 6자리까지 보여줍니다. 보기 좋게 줄이려면 %.1f를 쓰세요.

서식과 값의 종류를 맞추세요%d에 실수를, %f에 정수를 넣으면 엉뚱한 값이 나옵니다. 서식의 개수와 값의 개수가 다를 때도 마찬가지예요. -Wall을 켜고 컴파일하면 이런 실수를 경고해 줍니다.

2-3scanf로 입력받기

키보드 입력은 scanf로 받습니다. 서식은 printf와 비슷하지만 변수 이름 앞에 &를 붙입니다.

#include <stdio.h>

int main(void) {
    int age;

    printf("나이를 입력하세요: ");
    scanf("%d", &age);
    printf("내년에는 %d살이 됩니다.\n", age + 1);
    return 0;
}
나이를 입력하세요: 23
내년에는 24살이 됩니다.

(출력 중 23은 직접 키보드로 입력한 값입니다.)

왜 &가 필요할까?scanf는 입력받은 값을 변수 안에 채워 넣어야 합니다. 그러려면 변수의 값이 아니라 변수가 있는 위치(주소)를 알아야 해요. &age는 "age의 주소"라는 뜻입니다. 정확한 원리는 7장 포인터에서 풀립니다. 일단은 scanf에는 &를 붙인다로 기억하세요. (문자열은 예외인데, 5장에서 다룹니다.)

두 개 이상을 한 번에 받을 수도 있고, 자료형에 맞는 서식을 써야 합니다. printf에서는 %f였던 double이 scanf에서는 %lf인 점에 주의하세요.

#include <stdio.h>

int main(void) {
    int a, b;
    double h;

    printf("정수 두 개를 입력하세요: ");
    scanf("%d %d", &a, &b);
    printf("합: %d\n", a + b);

    printf("키(cm)를 입력하세요: ");
    scanf("%lf", &h);          // double은 %lf!
    printf("키: %.1f cm\n", h);
    return 0;
}

2-4형변환과 정수 나눗셈 함정

C에서 정수끼리 나누면 결과도 정수입니다. 소수 부분은 반올림이 아니라 그냥 버려져요. 그래서 7 / 2는 3.5가 아니라 3입니다.

#include <stdio.h>

int main(void) {
    int a = 7, b = 2;

    printf("a / b = %d\n", a / b);            // 정수 나눗셈
    printf("a %% b = %d\n", a % b);            // 나머지

    double wrong = a / b;                      // 나눈 '다음'에 double로 바뀜
    double right = (double)a / b;              // 나누기 '전에' 바꿈
    printf("wrong = %f\n", wrong);
    printf("right = %f\n", right);
    printf("7 / 2.0 = %.1f\n", 7 / 2.0);

    int pi100 = (int)3.99;                     // 소수 부분은 버림
    printf("(int)3.99 = %d\n", pi100);
    return 0;
}
a / b = 3
a % b = 1
wrong = 3.000000
right = 3.500000
7 / 2.0 = 3.5
(int)3.99 = 3
  • double wrong = a / b; — 정수끼리 먼저 나눠 3이 된 뒤에 double로 바뀌어서 3.0이 됩니다.
  • (double)a / b — 나누기 전에 a를 double로 바꾸므로 3.5가 나옵니다. 이렇게 괄호로 자료형을 적어 값을 바꾸는 것을 형변환(캐스팅)이라 합니다.
  • 한쪽이라도 실수면(7 / 2.0) 결과는 실수입니다.
  • %(나머지)는 정수끼리만 쓸 수 있습니다. printf에서 퍼센트를 출력하려면 %%라고 씁니다.

5-1배열 기본

점수 5개를 저장하려고 변수를 5개 만들 순 없겠죠? 배열은 같은 자료형의 칸을 붙여서 한 번에 만드는 것입니다. 각 칸은 0번부터 시작하는 번호(인덱스)로 접근합니다.

#include <stdio.h>

int main(void) {
    int scores[5] = {90, 85, 77, 62, 100};
    int n = sizeof(scores) / sizeof(scores[0]);   // 칸 수 = 5

    int sum = 0;
    for (int i = 0; i < n; i++) {
        printf("scores[%d] = %d\n", i, scores[i]);
        sum += scores[i];
    }
    printf("합계 %d, 평균 %.1f\n", sum, (double)sum / n);

    scores[2] = 80;                               // 값 바꾸기
    printf("scores[2]를 바꾼 뒤: %d\n", scores[2]);
    return 0;
}

  • int scores[5] = {...}; — 칸 수는 대괄호 안에 씁니다.
  • sizeof(scores) / sizeof(scores[0]) — 배열 전체 크기를 한 칸 크기로 나눠 칸 수를 구합니다. 이 방법은 배열이 선언된 같은 함수 안에서만 통합니다(6~7장에서 이유가 나옵니다).
  • 평균을 구할 때 (double)sum / n으로 형변환한 것을 기억하죠? 2장의 정수 나눗셈 함정입니다.

  1. %s는 공백이 나오면 거기서 멈춥니다. "Kim Minsu"를 입력하면 "Kim"만 받아요.

int main(void) {

}

6-2값에 의한 전달

C의 함수는 인자의 복사본을 받습니다. 그래서 함수 안에서 매개변수를 바꿔도 원래 변수는 변하지 않아요. 두 값을 바꾸는 swap 함수를 만들어 보면 알 수 있습니다. 아래는 의도대로 동작하지 않는 예입니다.

#include <stdio.h>

void swap(int a, int b) {
    int tmp = a;
    a = b;
    b = tmp;
    printf("swap 안:  a=%d, b=%d\n", a, b);
}

int main(void) {
    int x = 1, y = 2;
    swap(x, y);
    printf("swap 후: x=%d, y=%d\n", x, y);
    return 0;
}
swap 안:  a=2, b=1
swap 후: x=1, y=2

함수 안에서는 a와 b가 바뀌었지만, main의 x와 y는 그대로입니다. a, b는 x, y의 복사본이었기 때문이에요. 원본을 바꾸려면 값이 아닌 위치(주소)를 넘겨야 합니다. 이것이 바로 다음 7장의 포인터가 필요한 이유입니다.

7. 포인터

C의 꽃이자 최대 난관. 하지만 "변수의 위치를 가리키는 변수"라는 한 문장만 붙잡으면 생각보다 단순합니다.

7-1주소(&)와 역참조(*)

모든 변수는 메모리 어딘가에 있고, 그 위치를 주소라고 합니다. 변수 앞에 &를 붙이면 그 주소가 됩니다. 이 주소를 담는 변수가 포인터입니다.

  • int *p; — "int 변수의 주소를 담는 포인터 p"를 선언 (자료형 뒤의 *)
  • p = &x; — p에 x의 주소를 저장
  • *p — p가 가리키는 곳으로 찾아가서 그 값을 읽거나 씀 (역참조)

선언할 때의 *와, 사용할 때의 *p는 모양이 같지만 다른 뜻이니 헷갈리지 마세요.

#include <stdio.h>

int main(void) {
    int x = 10;
    int *p = &x;                      // p에 x의 주소를 저장

    printf("x  = %d\n", x);
    printf("*p = %d\n", *p);          // p가 가리키는 곳의 값
    printf("p == &x ? %d\n", p == &x);

    *p = 20;                          // p를 통해 x를 바꾼다
    printf("x  = %d\n", x);
    return 0;
}
x  = 10
*p = 10
p == &x ? 1
x  = 20

*p = 20;으로 p를 통해 x가 20이 되었어요. 주소 자체를 출력하는 %p도 있지만 값이 실행할 때마다 달라서 여기서는 쓰지 않았습니다.

이제 2장의 의문이 풀립니다. scanf("%d", &age)는 age의 주소를 넘겨서, scanf가 그 위치를 찾아가 값을 채워 넣게 하는 것이었어요.

7-2포인터로 swap 성공시키기

6장에서 실패했던 swap을 주소를 넘기는 방식으로 고쳐 봅시다. 주소를 받으면 함수가 원본을 찾아가 바꿀 수 있습니다.

#include <stdio.h>

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);                     // 주소를 넘긴다
    printf("swap 후: x=%d, y=%d\n", x, y);
    return 0;
}
swap 후: x=2, y=1
  • 호출: swap(&x, &y) — 값 대신 주소를 넘김
  • 정의: int *a, int *b — 주소를 받는 포인터 매개변수
  • 내용: *a, *b — 찾아가서 읽고 씀

7-3배열과 포인터의 관계

배열 이름은 첫 번째 칸의 주소처럼 쓰입니다. 그래서 int *p = arr;가 가능하고, p[1]과 *(p + 1)은 같은 말입니다. 포인터에 1을 더하면 "다음 칸"(int면 4바이트 뒤)으로 갑니다.

#include <stdio.h>

int sum_array(int *a, int n) {        // int a[] 라고 써도 똑같다
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i];
    }
    return sum;
}

int main(void) {
    int arr[3] = {10, 20, 30};
    int *p = arr;                     // 배열 이름 = 첫 칸의 주소

    printf("*p       = %d\n", *p);
    printf("p[1]     = %d\n", p[1]);
    printf("*(p + 2) = %d\n", *(p + 2));

    for (int i = 0; i < 3; i++) {
        printf("%d ", *(p + i));
    }
    printf("\n");

    printf("합계: %d\n", sum_array(arr, 3));
    return 0;
}
*p       = 10
p[1]     = 20
*(p + 2) = 30

8-1struct와 멤버 접근

학생 한 명의 정보를 변수 세 개로 따로 들고 다니면 번거롭죠. 구조체(struct)는 여러 변수(멤버)를 한 묶음의 새로운 자료형으로 만듭니다.

  • 변수에서 멤버 접근: 변수.멤버 (점)
  • 포인터에서 멤버 접근: 포인터->멤버 (화살표). p->gpa는 (*p).gpa를 줄여 쓴 것입니다.
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int id;
    double gpa;
};

void give_bonus(struct Student *s) {
    s->gpa += 0.1;                    // 포인터로 받으면 -> 를 쓴다
}

int main(void) {
    struct Student s1 = {"김콤스", 20250001, 3.5};

    printf("%s (%d) 학점 %.1f\n", s1.name, s1.id, s1.gpa);

    s1.id = 20250002;                 // 멤버 바꾸기
    strcpy(s1.name, "이광운");        // 문자열은 = 가 아니라 strcpy
    give_bonus(&s1);
    printf("%s (%d) 학점 %.1f\n", s1.name, s1.id, s1.gpa);
    return 0;
}
김콤스 (20250001) 학점 3.5
이광운 (20250002) 학점 3.6
  • 구조체도 함수에 그냥 넘기면 복사본이 갑니다. 원본을 바꾸려면 7장처럼 &s1로 주소를 넘기고, 받는 쪽은 ->를 씁니다.
  • char 배열 멤버에는 =로 문자열을 대입할 수 없어서 strcpy를 썼습니다(5장).
  • 구조체 정의 끝의 세미콜론 };을 빼먹기 쉬우니 주의하세요.

9-33단계: 완성 — 랜덤 정답과 기회 제한

마지막으로 정답을 무작위로 정하고(rand), 기회를 7번으로 제한합니다. 이런 상수는 #define MAX_TRIES 7로 이름을 붙여 두면 나중에 고치기 쉽습니다. srand(time(NULL))은 "현재 시간을 씨앗으로 써서 실행할 때마다 다른 수가 나오게" 하는 관용구입니다.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define MAX_TRIES 7

int main(void) {
    srand((unsigned)time(NULL));          // 실행할 때마다 다른 숫자가 나오게
    int secret = rand() % 100 + 1;        // 1 ~ 100
    int guess;
    int tries = 0;

    printf("=== 숫자 맞히기 (기회 %d번) ===\n", MAX_TRIES);

    while (tries < MAX_TRIES) {
        printf("[%d/%d] 숫자: ", tries + 1, MAX_TRIES);
        scanf("%d", &guess);
        tries++;

        if (guess == secret) {
            printf("정답! %d번 만에 맞혔어요.\n", tries);
            return 0;
        } else if (guess < secret) {
            printf("더 커요\n");
        } else {
            printf("더 작아요\n");
        }
    }

    printf("실패! 정답은 %d였어요.\n", secret);
    return 0;
}

10-3scanf 입력 버퍼 문제

숫자를 scanf로 받은 직후에 글자 하나를 %c로 받으면, 입력이 건너뛰어지는 현상이 있습니다. 키보드로 5를 치고 엔터를 누르면 5와 엔터(\n)가 둘 다 입력 버퍼에 들어가는데, %d는 5만 가져가고 엔터를 남겨 두기 때문입니다. 다음 %c가 그 남은 엔터를 읽어 버려요. 아래는 의도대로 동작하지 않는 예입니다.

#include <stdio.h>

int main(void) {
    int n;
    char c;

    printf("숫자: ");
    scanf("%d", &n);
    printf("문자: ");
    scanf("%c", &c);                      // 남아 있던 엔터를 읽어 버린다!
    printf("n=%d, c의 코드값=%d\n", n, c);
    return 0;
}
숫자: 5
문자: n=5, c의 코드값=10

"문자:"를 묻자마자 아무것도 입력하지 않았는데 끝나 버렸죠. c의 코드값 10이 바로 엔터(\n)입니다. 해결은 간단합니다. %c 앞에 공백 한 칸을 넣으면 남은 공백·엔터를 건너뛰고 읽습니다.

#include <stdio.h>

int main(void) {
    int n;
    char c;

    printf("숫자: ");
    scanf("%d", &n);
    printf("문자: ");
    scanf(" %c", &c);                     // %c 앞의 공백: 남은 공백/엔터를 건너뛴다
    printf("n=%d, c=%c\n", n, c);
    return 0;
}
숫자: 5
문자: A
n=5, c=A

(%d, %lf, %s는 알아서 공백·엔터를 건너뛰기 때문에 이 문제는 %c에서만 생깁니다.)

  • 동적 할당 (malloc / free) — 배열 크기를 실행 중에 정하고 싶을 때. 포인터를 이해했다면 바로 이어서 배울 수 있어요. 맛보기:
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    printf("몇 개? ");
    scanf("%d", &n);

    int *a = malloc(n * sizeof(int));     // 실행 중에 n칸을 빌린다
    if (a == NULL) {
        printf("메모리 부족\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        a[i] = (i + 1) * 10;
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");

    free(a);                              // 다 썼으면 반드시 돌려준다
    return 0;
}
